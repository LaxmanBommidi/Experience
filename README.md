🚀 Experience API Backend (Node.js + Express + Prisma + PostgreSQL)

A production-ready backend API for authentication and blog management built using Node.js, Express, Prisma ORM, PostgreSQL, and JWT authentication.

📌 Features
🔐 Authentication (Register, Login, Logout, Refresh Tokens)
🛡️ JWT-based Authorization
📝 Blog CRUD (Create, Read, Update, Delete)
🔗 Prisma ORM with PostgreSQL
⚡ Clean Architecture (Controller → Service → DB)
🧱 Tech Stack
Backend: Node.js, Express
Database: PostgreSQL
ORM: Prisma
Auth: JWT (Access Token)
Hashing: argon2
